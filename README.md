# Jungle Adventure Game 🐾

A fun, text-based jungle adventure game built in Python.  
In this game, you play as an explorer searching for a hidden treasure deep inside the mysterious jungle.  
Make smart choices to survive — but beware, you have limited fuel and only three lives!

---

## 🎮 How to Play

1. Run the game in your terminal or Python IDE.
2. Follow the on-screen instructions and make your choices.
3. Manage your fuel and lives carefully to find the treasure.
4. If you lose all lives or fuel, the game ends.
